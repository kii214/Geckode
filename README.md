# GECKODE - Website Kursus Coding

Selamat datang di repositori **GECKODE**, sebuah website kursus coding berbasis web yang dibuat untuk memudahkan belajar pemrograman bagi pemula hingga tingkat lanjut.

---

---

## Deskripsi Proyek
GECKODE adalah platform belajar coding yang menyediakan berbagai kursus dengan materi lengkap dan mudah dipahami. Website ini dibuat menggunakan:

- Bahasa pemrograman PHP untuk backend dan pengambilan data dari database MySQL
- HTML dan CSS untuk tampilan antarmuka yang responsif dan estetis
- MySQL sebagai basis data penyimpanan kursus dan materi
- Struktur sederhana dan ringan sehingga mudah dikembangkan dan dimodifikasi

Fitur utama yang tersedia di GECKODE:

- Daftar kursus dengan deskripsi dan gambar pendukung
- Halaman materi yang menampilkan detail materi per kursus
- Navigasi yang mudah dan user-friendly
- Footer dengan informasi hak cipta dan tahun aktif
